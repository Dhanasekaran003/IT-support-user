# FieldLink Client Portal

Book IT field support, track tickets, assets, AMC coverage, and invoices against live APIs.

- Dev: `npm run dev` → http://localhost:5175
- Register at `/register` with first name, last name, email, and password. Company details are updated on Profile.
- Seeded login: `vikram@apexlogistics.in` / `Client@123`
- Invited users get an email with a temporary password and must change it on first login.
